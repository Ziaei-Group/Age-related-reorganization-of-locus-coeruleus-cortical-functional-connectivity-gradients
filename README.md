# Age-related reorganization of locus coeruleus–cortical functional connectivity gradients

Code, source data and stimuli for the manuscript (Ziaei Group, Kavli Institute for Systems Neuroscience, NTNU).

## Contents

| Folder | What it holds |
|---|---|
| `Analysis Scripts/` | `Gradient.mlx` – MATLAB live script computing the LC–cortical connectivity gradients. `age_dispersion_behaviour_functions.py` – Python functions for group comparisons of gradient dispersion (with covariate adjustment), brain–behaviour correlations with permutation testing, FDR correction, and age-moderation analysis. `surface_plot.py` – projects gradient maps onto the fsaverage surface for figures. |
| `Source Data/` | `Source_data_LC_Cortex_Gradient.xlsx` – values underlying each figure. |
| `Movie stimuli/` | The two naturalistic movie clips used during fMRI (stored with Git LFS; install [Git LFS](https://git-lfs.com) before cloning). |
